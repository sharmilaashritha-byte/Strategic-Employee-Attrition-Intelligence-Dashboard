Strategic Employee Attrition Intelligence Dashboard

The Strategic Employee Attrition Intelligence Dashboard is a Power BI project that analyzes employee attrition and workforce trends. It presents key KPIs such as 5,000 employees, 18% attrition rate, 895 employees left, 4,105 still working, 7K average monthly income, 6.7 average years at company, and 60% AI adoption. The dashboard uses interactive visualizations to analyze attrition by department, job role, work mode, and AI-tool usage, helping organizations understand workforce patterns and support data-driven HR decisions.
